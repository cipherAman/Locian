Core Capabilities

Engineered for Silicon Independence

Native Android optimizations paired with modern quantized GGUF inference.

01 / PRIVACY

100% Offline Execution

Zero network requests, zero background telemetry, and zero remote APIs. Prompts, model weights, and conversation histories remain strictly inside local device storage.

02 / HARDWARE

Dynamic CPU Binary Dispatch

Startup CPU capability detection selectively loads native binaries compiled for ARM NEON, ARMv8.2 FP16, Dot-Product, and ARMv8.4 i8mm instructions.

03 / MEMORY

Adaptive Memory Guard

Automated RAM profiling calibrates KV cache allocation and context limits to prevent Android Low-Memory Killer (LMK) process termination.

04 / REASONING

Chain-of-Thought Folding

Full support for reasoning models (DeepSeek R1, Qwen). Dedicated collapsible containers parse internal reasoning steps separately from the final answer.

05 / TELEMETRY

Real-Time Execution Telemetry

Precise post-generation telemetry: Decode Speed (tok/s), Time to First Token (TTFT in ms), and total output token count displayed on every reply.

06 / STORAGE

Resumable Downloads & Sideload

In-app catalog with HTTP Range byte-level resume support and SHA-256 verification. Sideload any standard GGUF file via the system document picker.

System Design

Clean Architecture & Native NDK Pipeline

Strict separation of concerns ensures crash-free memory management and high maintainability.

Multi-Module Architecture Hierarchy

Each layer communicates via Kotlin Coroutines Flow, reactive StateFlows, and Hilt dependency injection.

:feature-*
UI Layer: feature-chat, feature-models, feature-settings, feature-conversations built with Jetpack Compose Material 3.
:domain-inference
Domain Layer: Clean Use Cases (StreamChatResponse, LoadModel, ManageConversation) independent of Android frameworks.
:data-*
Data Layer: Room SQLite DB (message history), DataStore (inference sampling prefs), OkHttp (resumable range downloads).
:inference
Native Bridge: C++ JNI bridge, CPU feature dispatcher, dynamic llama.cpp cross-compilation target selection.

Dynamic CPU Binary Dispatching

Getting Started

Install & Run Locian in Minutes

Get the prebuilt release APK or compile locally with Android Studio and NDK.

1. Download Release APK

Pre-compiled APK signed and packaged with multi-target NDK binaries for Android 8.0+:

Download Latest APK

2. Install via ADB Command

Push directly to your connected device with USB debugging enabled:

adb install -r Locian-v1.0.0.apk

3. Build from Source

Requires Android Studio Ladybug+, JDK 17, and Android NDK r27+:

git clone https://github.com/cipherAman/Locian.git cd Locian ./gradlew assembleRelease
