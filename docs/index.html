Write a clean Python script demonstrating asynchronous task queues.

Sure, here is a clean Python script using asyncio to implement an in-memory asynchronous task queue:

PYTHON 
import asyncio
from typing import Any

class TaskQueue:
    def __init__(self, max_concurrency: int = 3):
        self.queue = asyncio.Queue()
        self.semaphore = asyncio.Semaphore(max_concurrency)

    async def enqueue(self, task_name: str, payload: Any):
        await self.queue.put((task_name, payload))
        print(f"📦 [Queued] {task_name}")

    async def worker(self, worker_id: int):
        while True:
            task_name, payload = await self.queue.get()
            async with self.semaphore:
                print(f"⚡ [Worker {worker_id}] Executing: {task_name}")
                await asyncio.sleep(0.5)
            self.queue.task_done()

System Design

Clean Architecture & Native NDK Pipeline

Strict separation of concerns ensures crash-free memory management and high maintainability.

Multi-Module Architecture Hierarchy

Each layer communicates via Kotlin Coroutines Flow, reactive StateFlows, and Hilt dependency injection.

:feature-*
UI Layer: feature-chat, feature-models, feature-settings, feature-conversations built with Jetpack Compose Material 3.
:domain-inference
Domain Layer: Clean Use Cases (StreamChatResponse, LoadModel, ManageConversation) independent of Android frameworks.
:data-*
Data Layer: Room SQLite DB (message history), DataStore (inference sampling prefs), OkHttp (resumable range downloads).
:inference
Native Bridge: C++ JNI bridge, CPU feature dispatcher, dynamic llama.cpp cross-compilation target selection.

Getting Started

Build & Run in Minutes

Compile Locian locally using Android Studio or the command line.

1. Prerequisites

  • Android Studio Ladybug or newer
  • JDK 17 or JDK 21
  • Android NDK r27+ and CMake 3.22.1
  • Physical device with Android 8.0+ (API 26+) and 4 GB+ RAM

2. Clone & Build Debug APK

Assemble the debug APK with multi-target NDK binaries:

./gradlew assembleDebug

3. Install onto Device

Connect device via USB with ADB debugging enabled:

adb install -r app/build/outputs/apk/debug/app-debug.apk
